# Udonite

**VRChat world scripting that feels like normal Unity C#.**

Write a `MonoBehaviour` and Udonite compiles it to Udon. No dialect to learn and no list of forbidden keywords to memorise: generics, interfaces, records, LINQ, dictionaries, delegates and events, coroutines, `async`, pattern matching, and networking with typed payloads.

Udonite is free, networking included.

## Install

Add this listing to the VRChat Creator Companion:

```
https://udonite.github.io/vpm/index.json
```

Then add **Udonite** from the package list. Or press **Add to VCC** on the [listing page](https://udonite.github.io/vpm/).

Documentation: **[docs.udonite.com](https://docs.udonite.com)**
