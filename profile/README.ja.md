# Udonite

**VRChat のワールド制作を、普通の Unity C# で。**

`MonoBehaviour` を書けば、Udonite がそれを Udon にコンパイルします。覚えるべき方言も、使えないキーワードの一覧もありません。ジェネリクス、インターフェース、レコード、LINQ、ディクショナリ、デリゲートとイベント、コルーチン、`async`、パターンマッチング、そして型付きペイロードのネットワーク処理。

Udonite は無料です。ネットワーク機能も含みます。

## インストール

VRChat Creator Companion に次のリスティングを追加してください。

```
https://udonite.github.io/vpm/index.json
```

その後、パッケージ一覧から **Udonite** を追加します。または[リスティングページ](https://udonite.github.io/vpm/)の **Add to VCC** を押してください。

ドキュメント: **[udonite.dajno.com](https://udonite.dajno.com/?lang=ja)**
